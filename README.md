# Act3D — project page

Website for *Learning to Think and Explore in 3D World*.

Static single page: `index.html`, styles in `static/css/style.css`, figures in
`static/images/`. No build step — open `index.html`, or serve the directory.

Figures are exported from the paper's generators in `overleaf-3d/figs/`; regenerate
there and re-export the PNGs if numbers change.
